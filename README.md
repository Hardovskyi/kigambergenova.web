# Kamila Igambergenova

Architecture portfolio for Kamila Igambergenova — selected projects, field practice, and computational design.

**Website:** [hardovskyi.github.io/kigambergenova.web](https://hardovskyi.github.io/kigambergenova.web/)

The site presents her work as an architectural designer interested in how buildings connect people, places, and everyday use. It includes four Selected Works chapters (Community Room, The Cove, Village in the City, The Wave), Frames of Practice from Japan, Texas, and India, Grasshopper studies, photography, and physical models, with résumé and portfolio PDFs available to download.
